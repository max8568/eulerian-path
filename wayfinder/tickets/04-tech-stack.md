## Question

這個遊戲要用什麼技術做？要決定：

- 純 HTML 加 JavaScript 的單一網頁，還是用前端框架
- 圖要用 SVG 還是 Canvas 畫
- 進度存在瀏覽器的哪裡
- 1000 關的關卡資料要放成一個檔一次載入，還是分批載入

「小朋友用手指畫線，怎麼操作最順」的雛形用單一 HTML 檔加 SVG 做，在手機上可以玩，見那張票的結論和 [prototypes/02-drawing/index.html](../prototypes/02-drawing/index.html)。

## Resolution

2026-10-12 和使用者討論後定案：

- **不用框架，也不打包。** 純 HTML、CSS、JavaScript，檔案直接放上網站就能玩，跟雛形一樣。
- **一筆畫的判斷放在一個獨立的 JavaScript 檔。** 包括從某個點出發還畫不畫得完、下一條可以畫的線、可以出發的點。遊戲裡的提示和產生關卡的程式都用這同一個檔，再用 Node 內建的測試工具寫測試。
- **圖用 SVG 畫。** 提示閃線、點的跳動這些動畫用 CSS 做。
- **進度存在瀏覽器的 localStorage**，每個頭像各存一份。
- **1000 關的關卡資料放在一個 JSON 檔**，打開時一次載入，壓縮後大約 100 KB。
- **產生 1000 張圖的程式用 JavaScript（Node）寫**，在使用者的電腦上跑，產生關卡檔，不會放上網站。
- **做成可以加入主畫面、可以離線玩的網頁**：加一個寫 App 名字和圖示的檔案，再加一個負責把遊戲存在裝置上的檔案。打開過一次網址之後，沒有網路也能玩。遊戲更新後，下次打開時換成新版。
- **裝置**：家裡用的是 iPad Pro 11 吋（M4）。直著拿、橫著拿都要排好。直著拿時，退一步、重來、提示三個按鈕放下方；橫著拿時放右側，圖畫大一點。這一點補充了「小朋友用手指畫線，怎麼操作最順」裡「按鈕放下方」的決定。
- **Safari 的 7 天規則**：網站 7 天沒打開，Safari 會刪掉它存的資料，加入主畫面的網頁不受這條限制（[WebKit 官方說明](https://webkit.org/blog/10218/full-third-party-cookie-blocking-and-more/)）。另外，Safari 分頁和主畫面圖示的資料是分開存的。使用者會自己把網址加入主畫面，所以遊戲裡不做「請加入主畫面」的提示。
